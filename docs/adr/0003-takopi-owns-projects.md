# Takopi owns the Project list; tg-agent only merges Telegram settings

Projects are registered inside the VM with `takopi init` (by the user via SSH or by an Agent on request from a Topic) and live in Takopi's `takopi.toml`, next to Takopi's Bindings and Sessions. tg-agent does not declare Projects in its Config; on Update it merges only the keys it owns (Telegram credentials, Allowed Users, topic mode) into the existing `takopi.toml`. Declaring them on the Host was rejected: adding a Project would require a Host-only, minutes-long Update, and the reproducibility it bought is moot because the VM is persistent.
